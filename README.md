# CSMA Simulator (imiris)

Дискретно-событийный симулятор сети **CSMA** (Carrier Sense Multiple Access): N хостов делят общий канал, генерируют пакеты по Пуассону и передают их с учётом занятости канала и очередей адаптеров.

Проект — лабораторная работа: симулятор на C++, скрипты анализа/поиска на Python, графики и материалы к защите.

## Возможности

- Модель CSMA с проверкой занятости канала
- N независимых хостов с очередями (`deque`)
- Пуассоновский поток пакетов (экспоненциальные интервалы Exp(α))
- Ограниченные и неограниченные очереди (`--qlimit`)
- Метрики: потери, попытки, длины очередей, утилизация канала
- Экспорт результатов в CSV
- Скрипты массовых прогонов, бинарного поиска и построения графиков

## Быстрый старт

Одиночный запуск (вывод в консоль):

```bash

```

С записью в CSV:

```bash
./csma_sim --N 10 --alpha 50 --simtime 10 --csv results.csv
```

## Параметры симулятора

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| `--N` | `10` | число хостов |
| `--alpha` | `10` | интенсивность прибытия пакетов на хост (1/с) |
| `--simtime` | `10` | время симуляции (с) |
| `--B` | `100` | пропускная способность канала (Мбит/с) |
| `--L` | `3` | длина канала (м) |
| `--l` | `1500` | размер пакета (байты) |
| `--qlimit` | `-1` | лимит очереди (`-1` = без ограничений) |
| `--csv` | — | файл для дозаписи результатов |

### Производные величины

```text
tx_time    = (l * 8) / (B * 1e6)     # время передачи пакета, с
prop_delay = L / 2e8                 # задержка распространения, с
```

Интервалы между пакетами на каждом хосте: `Exp(alpha)`, средний интервал `1/alpha`.

## Как работает симуляция

Дискретно-событийная модель на приоритетной очереди событий (min-heap по времени).

**Типы событий**

- `EVT_ARRIVAL` — прибытие пакета на хост
- `EVT_TX_END` — конец передачи

**Логика CSMA (упрощённо)**

1. При прибытии пакета: если канал свободен, чужих очередей нет и своя очередь пуста → передача сразу.
2. Иначе пакет ставится в очередь хоста (или дропается при переполнении).
3. По окончании передачи выбирается пакет с наименьшим `arrival_time` среди всех очередей (глобальный FIFO) и начинается следующая передача.
4. Длительность занятости канала для пакета: `tx_time + prop_delay`.

Флаг `somebody_waiting` не даёт новому пакету «перепрыгнуть» уже ожидающие — это защита от голодания.

## Метрики (выход)

| Метрика | Смысл |
|---------|--------|
| `lost_fraction` (Хар1) | доля отброшенных пакетов |
| `avg_attempts_per_packet` (Хар2) | среднее число попыток на пакет |
| `avg_queue_len_*` (Хар3) | средняя длина очереди (интеграл по времени) |
| `max_queue_len_over_hosts` | максимум длины очереди по всем хостам |
| `channel_util` (Хар4) | доля времени, когда канал занят |

Средняя длина очереди считается методом «площади под графиком»:

```text
queue_time_area[i] += queue_len[i] * dt
avg_queue_len[i]    = queue_time_area[i] / simTime
```

Утилизация:

```text
channel_util = cumulative_channel_busy / simTime
```

```bash
    ./csma_sim --N $N --alpha $alpha --simtime 10 --csv results.csv
  done
done
```

Скрипт ожидает именованные столбцы `N`, `alpha`, `channel_util`, `loss_fraction`, `max_queue` (то есть CSV **с заголовком** от текущего `csma_sim`).

## Вспомогательные скрипты

### Максимальное N при `channel_util ≤ 0.5`

Бинарный поиск по N (вызывает `./csma_sim`):

```bash
python3 find_max_n.py 50
```

### Максимальное N со стабильной очередью

Очередь считается стабильной, если

```text
maxQ(T2=40) − maxQ(T1=20) ≤ 2
```

```bash
python3 find_stable_queue.py 50
```

### Зависимость утилизации от длины пакета

```bash
python3 channel_util_vs_l.py <N> <alpha> [l_min] [l_max] [l_step]
# пример:
python3 channel_util_vs_l.py 50 50 100 5000 100
```

Сохраняет `channel_util_vs_l.png`.

Все Python-скрипты предполагают, что `./csma_sim` лежит в текущей директории.

## Архитектура кода (`csma_sim.cpp`)

| Сущность | Роль |
|----------|------|
| `Packet` | id, host, arrival_time, attempts |
| `Event` | time, type, host, pkt_id |
| `EventComp` | компаратор для min-heap по времени |
| `priority_queue<Event>` | календарь событий |
| `vector<deque<Packet>>` | очередь пакетов каждого хоста |

Основной цикл: взять событие → обновить интегралы очередей → обработать ARRIVAL / TX_END → повторить до `simTime`.

## Замечания

- Симуляция стохастическая (`mt19937_64` + `random_device`): повторные запуски с теми же параметрами дают близкие, но не идентичные числа.
- Старый `results.csv` без заголовка или с другим набором столбцов лучше пересобрать перед `plot_results.py`.
- Бинарник `csma_sim` в репозитории — для вашей платформы; после правок `csma_sim.cpp` перекомпилируйте.
